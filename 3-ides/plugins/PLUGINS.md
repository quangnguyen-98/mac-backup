# 🔌 JetBrains IDEs - Plugins Cần Cài

Cài thủ công qua: **Settings → Plugins → Marketplace**

---

## 📦 Plugins Chung (Cài cho TẤT CẢ IDE)

Cài 2 plugins này cho **WebStorm, PyCharm, GoLand, Android Studio**:

1. **GitToolBox** - Git inline blame, auto-fetch
2. **Rainbow Brackets** - Colorize brackets/parentheses

---

## 🎯 Plugins Riêng Từng IDE

### **WebStorm** (Vue + React)
- **Vue.js** (hoặc **Volar** nếu Vue 3) - Vue syntax, autocomplete
- **Import Cost** _(optional)_ - Show bundle size của imports

### **PyCharm** (Django + FastAPI)
- **.env files support** - Syntax highlighting cho .env
  - _NOTE: PyCharm 2024.3+ đã built-in, có thể skip_

### **Android Studio** (Android Native)
- **ADB Idea** ⭐ - Quick ADB commands (uninstall, clear data, restart)
- **JSON To Kotlin Class** ⭐ - Generate data classes từ JSON

### **GoLand**
- _(Không cần thêm gì - đã có plugins chung)_

### **DataGrip**
- _(Không cần cài gì - built-in đã đủ mạnh)_

## ⏱️ Thời Gian

~8-10 phút để cài tất cả plugins cho tất cả IDEs

**TIP:** Mở tất cả IDEs cùng lúc và cài song song!
